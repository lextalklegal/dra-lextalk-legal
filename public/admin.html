1. Import multilingual MCQs

Upload a CSV based on the supplied template. One row represents one question in one language. Reuse the same question_key for translations; keep the correct option letter the same across language rows. Imported questions remain Draft until reviewed.

2. Question bank review

Publish only after checking the source, correct answer, explanation and each translated option. You can filter the list by status.

4. Paid membership packages

Enter prices and activate plans only after the payment gateway is configured and tested. Plan prices are in Indian rupees; the backend stores paise.

5. Schedule a revision class

Use a meeting URL from the service you choose (for example, Zoom or Google Meet). Paid classes require an active plan; the platform itself does not host video.

6. Launch checklist

Before taking public payments, complete the account security, policy and test-bank checks.

  • Replace demo questions with your reviewed MCQ bank.
  • Verify all question translations and correct answer keys before publishing.
  • Set up official privacy/contact details and review the Terms/Privacy templates.
  • Configure Razorpay secrets, test mode, webhook and refund/support process before activating a plan.
  • Test student sign-up, free test one-time limit, expired timer, results and paid-entitlement lock.
  • Remove the one-time admin bootstrap secret after creating the administrator account.
