Create the first administrator

This page calls the one-time bootstrap endpoint. It works only when the Worker secret ADMIN_BOOTSTRAP_KEY is configured and no admin account exists yet.

Security: Set a long random bootstrap secret in Cloudflare first. After the admin account is created, delete that Worker secret. Do not share it or paste it into a public document.

Administrator created. Next, delete the ADMIN_BOOTSTRAP_KEY secret and sign in at /admin.html.
